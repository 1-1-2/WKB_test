# ADR 0001: 驱动路线——复用官方 `womic.sys` 未修改二进制，放弃自研驱动

- **状态**：已接受（2026-10）
- **决策者**：主理人（架构评审 R8 拍板）
- **影响范围**：Windows 客户端（`client/`）、安装链路（`tools/install.ps1`）、合规声明（仓库根 `NOTICE.md`）、已弃用的 `driver/` 目录定位
- **关联**：[`../NOTICE.md`](../NOTICE.md)（第三方来源声明全文）、[`../README.md`](../README.md)（仓库总览）

---

## 背景

本项目要在 Windows 上提供"手机当麦克风"的虚拟麦克风设备，内核层有两条路线：

1. **自研内核驱动**（`driver/` 目录，基于微软 `Windows-driver-samples` 的
   `audio/simpleaudiosimple` 改编，WaveRT 虚拟麦克风，说自有的 MicLink/WOMP 协议）；
2. **复用官方驱动**（WO Mic 的 `womic.sys`，北京吾理成技术，WHCP 签名，未修改二进制）。

自研路线进入实测后暴露出四类问题：

- **签名成本**：未采购 EV 代码签名证书的前提下，自研驱动无法在客户机默认加载
  （只能测试模式或手动去签名校验，装机体验不可接受）；
- **策略风险**：2026-04 起 Windows 驱动策略封杀非 WHCP 签名驱动，自研驱动正好撞在枪口上
  （官方三份 `.cat` 均已核查为 WHCP 签名，不受影响）；
- **行为差异**：驱动行为的细节（灌音协议握手链、全局门控、环形缓冲容量档位、
  防逆向返回值，见 [`driver-whitepaper.md`](driver-whitepaper.md)）是逆向出来的事实，
  自研驱动逐条复刻的代价高且永远滞后；
- **互通障碍**：与官方 Android app / 官方 Windows 客户端的互通（架构风险 R14）要求
  驱动侧行为与官方一致，自研驱动每一点差异都是一个新的未验证项。

同时，官方驱动本身质量可靠：EV 签名的内核驱动在 Win10 1607+ **免测试模式直接加载**，
"开箱即用安装"的前提成立。

## 决策

**复用 WO Mic 官方驱动 `womic.sys`（未修改二进制，WHCP 签名），本项目只做用户态。**

- 客户端（`client/`）负责：安装/卸载驱动（标准 SetupAPI/pnputil，不留私货）、
  按还原出的协议灌音（`\\.\WOMic` 握手链 + 环形缓冲）、Opus 解码与上行协议；
- `driver/` 目录**保留作技术参考**，不再是交付路径；
- 仓库持续跟踪官方驱动版本；协议规格以 [`driver-whitepaper.md`](driver-whitepaper.md) 为准。

## 后果

**正面**

- 开箱即用：WHCP 签名免测试模式加载，无签名证书采购与续期成本；
- 协议一致：灌音行为与官方完全相同，官方客户端与本项目客户端可互换对接
  （为 R14 官方互通验证消除驱动侧变量）；
- 维护面小：不维护 WDK 构建链、不追 Windows 内核音频栈变更。

**负面 / 代价**

- **合规未决**：WO Mic 官方 EULA 是否允许再分发，**未经法律确认**（见下节）；
- 分发受限：驱动二进制不能进公开源码库，只能随编译产物分发；
- 黑盒依赖：驱动的防逆向设计（如 `0x222001` 恒定返回失败）与行为细节只能逆向获得，
  官方升级驱动可能变更协议，需要重新取证；
- 版本追随：官方停更或改版时，本项目被动跟随。

## 备选方案

| 方案 | 结论 | 原因 |
|---|---|---|
| A. 自研内核驱动 | **已否决** | 签名成本 + 2026-04 驱动策略 + 行为差异复刻代价 + 互通障碍（见背景） |
| B. 运行时从官方 URL 下载驱动包 | **已否决** | 下载行为抬高杀软误报风险；且把安装链路绑死在官方 URL 可用性上 |
| C. 引导用户自备驱动包（`--driver-pack <dir>`） | **保留为兜底** | 完全规避再分发问题；代码链路已按此预留，若法律结论为"不允许再分发"即切换为主路径 |

## 合规状态

- **WO Mic 官方 EULA 是否允许再分发：未经法律确认**（架构评审 R8 遗留项）。
- 当前缓解措施（三项，详见 [`../NOTICE.md`](../NOTICE.md)）：
  1. **不进源码库、只随 exe 分发**：驱动包以 deflate 压缩内嵌资源形式只进编译产物
     `womic.exe`；源码库中对应文件已被 `.gitignore` 排除；
  2. **CI 现场提取 + sha256 校验**：构建时从官方安装包现场提取驱动套件并记录 sha256，
     仓库内不落任何驱动二进制，保证可复现同时不留分发物证；
  3. **NOTICE 声明**：`NOTICE.md` 完整披露第三方来源、版本、签名、用途与合规状态。
- 附加兜底（同样记录在 `NOTICE.md`）：提供完全的外置驱动通道（用户自备驱动目录），
  安装/卸载均走系统标准机制。
- **后续动作**：若获得"不允许再分发"的法律结论，切换至备选方案 C，引导用户自备驱动包。
